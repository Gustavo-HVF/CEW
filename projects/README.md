# projects/

Criado pelo CEW: um projeto por alvo (`cew run --projeto <nome> --alvo <caminho>`).
Cada pasta tem a estrutura do Craft Anything (`craft.json`, `capture/`, `app/`, `checks/`,
`investigation.cany/`, `inbox/`) mais os arquivos do CEW (`cew.json`, `estado.json`,
`inventario.json`, `plano_conversao.json`, `recomendacao_motor.json`, `relatorio_verificacao.json`,
`analise/`, `especificacoes/`, `tarefas_gemini/`, `referencias/`, `build/`, `web/`).
O conteudo das pastas de projeto nao vai para o git (ver `.gitignore`).
